# Student Task Manager – User Guide

## 1. Introduction
This application helps students organize and manage their academic tasks.

## 2. Adding a Task
Select option 1 and enter a task title. The application assigns a unique ID to the task.

## 3. Viewing Tasks
Select option 2 to display all tasks, including their IDs, titles, and completion status.

## 4. Completing a Task
Select option 3 and enter the ID of the task you want to mark as completed.

## 5. Deleting a Task
Select option 4 and enter the ID of the task you want to delete.

## 6. Exiting
Select option 5 to close the application.

## 7. Data Storage
Tasks are saved in `tasks.json`, allowing them to remain available when the application is restarted.

## 8. Running Tests
Use the following command:

`python -m unittest discover -s tests -v`
